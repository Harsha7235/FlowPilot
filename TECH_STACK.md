# TECH STACK

> **Official Technology Stack of the FlowPilot Engineering Platform**

Version: 1.0

# 1. Purpose

This document defines the official technology stack used throughout the FlowPilot platform.

Every technology included in this document has been selected based on scalability, maintainability, performance, community support, and long-term sustainability.

Unless there is a compelling architectural reason, these technologies should remain unchanged throughout the project lifecycle.
